# Code of conduct

This project is a place to build a frame-generation engine together. Everyone who takes part, in issues, pull
requests, reviews, discussions and the chat around them, is expected to:

- treat people with respect, whatever their experience, background or opinion;
- argue about code and measurements, not about people; a disagreement is settled by a test, a number or a decision
  record, not by who talks loudest;
- assume good faith, ask before judging, and accept that a maintainer may close a discussion that goes nowhere;
- keep the project's spaces free of harassment, insults, discrimination, sexualised language and publishing others'
  private information.

Maintainers remove content and, where needed, ban people who break these rules. Report a problem privately to the
maintainers of the `getflyhigh` organisation on GitHub (a private vulnerability report on this repository reaches
them too, and is read as a conduct report when it says so). Reports are handled confidentially and answered.
